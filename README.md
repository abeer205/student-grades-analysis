# student-grades-analysis

This project analyzes student performance using machine learning techniques such as **Linear Regression** and **Random Forest Classifier**.

It predicts:
- The **final grade** of a student.
- Whether the student will **pass or fail**.

🔍 Features
- Data generation and visualization using `matplotlib` and `seaborn`
- Regression model to predict numeric grades
- Classification model to predict pass/fail status
- Visual insights such as:
  - Grade distribution
  - Correlation heatmap
  - Confusion matrix

🧠 Technologies Used
- Python
- Pandas
- NumPy
- scikit-learn
- Matplotlib
- Seaborn
- Jupyter Notebook

 💾 Models Saved
- `grade_predictor_regression.pkl`
- `pass_fail_classifier.pkl`

💡 Insights
- Midterm and Project scores are most influential in determining success.
- Consistent homework and attendance improve prediction accuracy.
- Students with higher midterm scores have a better chance to pass.
